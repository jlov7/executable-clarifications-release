# Contributing

Use repository issues for non-sensitive defects with a minimal synthetic reproducer and expected/actual behavior. Keep confidential requirements and personal data out of issues and fixtures. Report security issues through an established private maintainer channel.

Use small changes with a failure-reproducing test, then the targeted regression and full stdlib suite. Run pinned Ruff and source, wheel and sdist gates in [evaluation](docs/EVALUATION.md). Browser changes require HTTP Chromium suites, including desktop/mobile recovery. Preserve negative controls and authored/model/human provenance.

Follow [V1 stability and release policy](docs/STABILITY.md). Do not add data, code or media without redistribution rights. Original code is [MIT licensed](LICENSE).
